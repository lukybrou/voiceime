# Código de conducta · Code of Conduct

## ES

VoiceIME es un proyecto pequeño y abierto. Para mantenerlo agradable para todo el mundo:

- Sé respetuoso en issues, PRs y Discussions.
- Las críticas van al código, no a las personas.
- Las preguntas de cualquier nivel son bienvenidas.
- No se toleran insultos, acoso ni comportamientos excluyentes.

Si ves algo que no cumple estas normas, abre un issue privado o contacta al mantenedor.

## EN

VoiceIME is a small open-source project. To keep it welcoming for everyone:

- Be respectful in issues, PRs and Discussions.
- Critique the code, not the person.
- Questions at any level are welcome.
- Insults, harassment and exclusionary behaviour are not tolerated.

If you see something that violates these norms, open a private issue or contact the maintainer.
